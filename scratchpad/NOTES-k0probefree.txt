# K0 lane, round of 2026-08-21 : the probe elimination

## What landed
Gtz/Wave/ProbeFreeHingeTrigger.lean (25 pins, all standard axioms).

The corank-one arm's whole swap/mirror machine mentioned the null probe w, an
eigenvector, which is not a design quantity.  The probe is now eliminated.

1. Adjugate law OFF the diagonal:
      pairMinorTotal a b c * ((a.w)(b.w)) = pairAdjOff a b c
   with  pairAdjOff a b c := (a.c)(b.c) - (a.b)(l_c - 1).
   Together with the landed diagonal law this is  adj N = e2 * s s^T  entrywise.
   Proof: four TWO-TERM column identities plus the normalization.  No rank
   hypothesis, no case split, no positivity.
      a11*s2 - a12*s1 = C*h2 - R*h3
      a22*s1 - a12*s2 = C*h1 - Q*h3
      a13*s2 - a12*s3 = P*h3 - Q*h2
      a13*s3 - a33*s1 = P*h2 - B*h1
   assembly: a12 - e2 s1 s2 = -[a12*hn + s1*c1 + s2*c2 + (s3*c3 - s2*c4)].

2. THE PROBE ELIMINATION.  For ANY vector v,
      pairMinorTotal a b c * (v.w)^2 = pairAdjForm a b c v
   where pairAdjForm is the adjugate quadratic form at the readings
   (v.a, v.b, v.c).  No eigenvector on the right.

3. The swap defect in pair currency:
      e2 * w^T (S_{C'} - 1) w = pairAdjForm a b c g_q - pairGapMinor b c .

4. THE PROBE-FREE HINGE TRIGGER.  If the shared pair is admissible, the swap
   weakly dominates, and pairAdjForm a b c g_q = pairGapMinor b c, then the
   design HAS A PARALLEL PAIR.  Contrapositive: at a primitive design every
   dominating swap over an admissible pair pays a STRICT polynomial inequality
   in leverages and inner products alone.

5. Shared-pair transfer: two dominators over a common pair compute that pair's
   minor from their own probes, so the shared pair minor is the exchange rate.

## MEASUREMENT ARTIFACT FOUND AND KILLED (report this)
Minimizing Phi = max_T lambda_min(S_T - I) over (6,3) designs from 14 random
starts converged to Phi ~ 1e-12 in 13 of 14 cases -- but EVERY one of those
"ties" had leverages of order 1e8 to 1e12 and one atom at leverage exactly
1.0000.  Those are dust-weight designs on the degenerate ray, not (6,3) ties:
weights collapse to ~1e-12 so the design is really a smaller one.  The census
taken there reported inadmissible pairs with NORMALIZED WEDGE EXACTLY 1.0 --
i.e. as far from parallel as possible -- which would have looked like a
refutation of "inadmissible implies parallel".  IT IS NOT.  It is the
degenerate ray.
With an honest weight floor tau = 0.05 the same optimizer floors at 6.3e-07 and
never reaches a tie from a random start; the split diamond (min weight 0.100,
Phi = 1.3e-15) shows the floored tie locus is non-empty but is codimension nine
and not reachable by random multistart.
RULE CONFIRMED: never census a tie found by descent without a weight floor.

Parseval transported through the probe elimination.
  sum_c t_c * pairAdjForm a b c g_c = pairMinorTotal a b c     (every design)
  sum_{d not in C} t_d * pairAdjForm a b c g_d
      = (1-t_a) q_bc + (1-t_b) q_ac + (1-t_c) q_ab
  t_d * pairAdjForm <= pairMinorTotal          (Parseval, termwise)
  pairAdjForm <= pairMinorTotal * leverage_d   (Cauchy-Schwarz)
  swap at x with d dominates  =>  t_d * q_yz <= pairMinorTotal
