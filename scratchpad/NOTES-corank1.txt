                                    (not merely a rank count)

given the endgame's per-pair upper bound  w_pq * beta_q^2 <= l_p * radius  with
radius = R^2(1 - <w,w'>^2), and the dominator's null readings a UNIT vector,

  beta_x^2 <= l_y l_z r,  beta_y^2 <= l_z l_x r,  beta_z^2 <= l_x l_y r

      1 <= radius * (l_x l_y + l_x l_z + l_y l_z) = radius * e2(l).

F28-11. THE SHARPENED DOMINATOR FLOOR (DominatorWedgeFloor.lean, section 3)
---------------------------------------------------------------------------
The K1 fork's dominator_bracket_floor DISCARDS the trace term of the shift
expansion. Keeping it is free and strictly better. With G = S_C - 1 PSD,
  [C]^2 = det(G+1) = 1 + tr G + e2(G) + det G,  all three invariants >= 0,
so keeping tr G = e1(l) - 3 gives
  dominator_bracket_floor_sharp       [xyz]^2 >= l_x + l_y + l_z - 2
  dominator_inside_wedge_floor_sharp  w_xy * l_z >= e1(l) - 2
  misalignment_floor_sharp_of_pairBounds   e1(l) - 2 <= radius * e2(l)
  dominator_trace_floor               e1(l) >= 3   (PSD gap has nonneg trace)
THE GAIN FACTOR IS e1(l) - 2, WHICH IS >= 1 ALWAYS because a weak dominator's
trace is at least the rank. So the sharp floor never loses and strictly improves
whenever the dominator carries slack.
CROSS-ARM CONSEQUENCE: the coordinator's composition K >= mu'^2/(R^2 e2(l))
becomes  K >= mu'^2 (e1(l) - 2)/(R^2 e2(l)).  If the K0 fight turns on the size
of e2(l), this is the lever -- the numerator now grows with the dominator trace.
MEASURED: 233902 dominators, ZERO violations. CAVEAT ON THE MEASUREMENT: my
sampler normalizes every atom to leverage 3, so e1 = 9 and the observed gain is
a flat 7 -- that is a SAMPLER ARTIFACT, not a general constant. The guaranteed
gain is e1(l) - 2 >= 1. Any successor re-measuring must vary the leverages.
LEAN GOTCHA (cost one build): rewriting the trace into `hshift` desynchronises
it from `he2`, which still mentions `Matrix.trace G`, and linarith then fails.
Derive the bound FIRST (1 + tr G <= [C]^2), then rewrite the trace in the bound.

F51-2. THE FOUR CHART POSITIVES ARE THE PLANE GAP, READ FOUR WAYS
==================================================================
B := g_y g_y' + g_z g_z'  (UNWEIGHTED plane pair moment).  The axis atom carries
a unit null direction of the dominator's gap, so THE GAP OF C IS B - 1, a 2x2
symmetric matrix.  In the frame (shared outside line first):
   B11 = y1^2+z1^2 , B22 = y2^2+z2^2 , B12 = y1y2+z1z2
ALL FOUR CHART POSITIVES ARE THAT GAP (verified exactly as ideal memberships):
   Wom = te*be^2 * (ty*y1^2 + tz*z1^2)          the plane pair's mass on the
                                                shared outside line
   Un  = te*be^2 * ty*tz * (B11 - 1)            first diagonal of the gap
   Vn  =           ty*tz * (B22 - 1)            second diagonal of the gap
   Dn  = te*be^2 * ty*tz * det(B - 1)           determinant of the gap
So THREE OF THE FOUR ARE EXACTLY THE SYLVESTER DATA OF B - 1, and a positive
definite plane gap (= the dominator's gap has corank exactly one) makes them
all strict.  THE CHART'S FOUR STRICT HYPOTHESES COST NOTHING BEYOND THE
STRATUM'S OWN DEFINITION.

MECHANISM (both elementary):
  (i) squaring the collinearity te*be*v = -td*al*p turns te^2be^2v^2 into
      td^2al^2p^2, so te*be^2*(td*p^2+te*v^2) = p^2*td*(td*al^2+te*be^2):
      THE ERASED CROSS MASS IS THE OUTSIDE PLANE MASS.  With r1 this gives Wom.
  (ii) THE CROSS LAW (new, design-free, reusable):
         c + d = 1  and  a*c = b*d   ==>   (a+b)*(ty*c + tz*d) = ty*b + tz*a
      at a = ty*y1^2, b = tz*z1^2, c = ty*y2^2, d = tz*z2^2 its two hypotheses
      are exactly r3 and r2-squared.  Cofactors: (ty-tz)*hac + (a*tz+b*ty)*hcd.
